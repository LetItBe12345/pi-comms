# 自动参与路由修复

验证日期：2026-10-10。

## 原因与修改

原 `router-v3` 提示词遗漏了规格中的“回答未解决问题”，仅强调纠错、补充专业知识和明显推进讨论。用最近群消息及通用 Agent 描述重放，“群里有几个 agent”连续三次返回空数组。

`router-v4` 优先邀请一个合适的 Agent 回答尚未回答的人类问题或处理求助。简短问题、普通问题、群成员目录问题均可邀请。无问题的寒暄、已解决请求或没有合适候选时保持安静。最多三个互补 Agent。

未调整在线、空闲、自动参与开关和冷却条件；这些条件不满足时仍跳过，恢复后不补触发旧消息。

## 验证

- 类型检查通过；Provider、Coordinator、Scheduler 共 20 项测试通过。
- 真实 DeepSeek API，通用 Agent 描述“擅长各种问题”，使用模拟在线且空闲的成员目录：
  - “你好”之后询问“群里有几个 agent”：三次均选中唯一候选。
  - 仅“你好”：返回空数组。
  - “请帮我解释 JavaScript 事件循环”：选中唯一候选。
  - 询问 Agent 数量后明确说已查看名单、无需回答：返回空数组。
- 真实调用仅验证路由选择，没有向群聊发消息，也没有触发 Pi Agent 执行。
- 模型判断具有不确定性；以上结果不保证每次判断完全一致。
